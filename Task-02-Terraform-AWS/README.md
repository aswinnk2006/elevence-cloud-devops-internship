# Task 02 – AWS Infrastructure Using Terraform

## Project Overview
This project demonstrates Infrastructure as Code (IaC) by provisioning AWS infrastructure using Terraform.

## Objective
To automate AWS resource creation and management using Terraform.

## Technologies Used
- Terraform
- Amazon Web Services (AWS)
- AWS EC2
- AWS Security Groups
- Ubuntu Linux

## Implementation
1. Installed and configured Terraform.
2. Configured the AWS provider.
3. Created Terraform configuration files.
4. Defined AWS Security Groups.
5. Configured EC2 instance resources.
6. Initialized Terraform using `terraform init`.
7. Validated configuration using `terraform validate`.
8. Reviewed infrastructure changes using `terraform plan`.
9. Applied infrastructure configuration using `terraform apply`.

## Expected Result
Successfully provisioned AWS infrastructure using Terraform configuration files.

## Key Learning Outcomes
- Infrastructure as Code.
- Terraform configuration.
- AWS resource management.
- Security Group configuration.
- Automated infrastructure provisioning.
