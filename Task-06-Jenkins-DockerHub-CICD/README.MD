# Task 06 – Jenkins CI/CD Pipeline with Docker Hub

## Project Overview
This project demonstrates an automated CI/CD pipeline using Jenkins to build Docker images and push them to Docker Hub.

## Objective
To automate Docker image building and publishing using Jenkins Pipeline.

## Technologies Used
- Jenkins
- Docker
- Docker Hub
- Git
- GitHub
- AWS EC2
- Ubuntu Linux

## Implementation
1. Configured Jenkins on AWS EC2.
2. Created a GitHub project repository.
3. Created a Jenkinsfile.
4. Configured Jenkins pipeline.
5. Connected Jenkins with GitHub.
6. Configured Docker Hub credentials in Jenkins.
7. Configured Docker image build stages.
8. Configured Docker image tagging.
9. Configured Docker Hub push stages.
10. Executed the Jenkins pipeline.
11. Verified the image in Docker Hub.

## Project Output
Successfully automated Docker image building and pushing through a Jenkins CI/CD pipeline.
