## 👨‍💻 About This Repository

This repository contains all six practical projects completed as part of my Cloud and DevOps Internship at **Elevence Skill Technology**.

The main objective of this internship was to gain hands-on experience with cloud infrastructure, automation, containerization, CI/CD pipelines, and application deployment.

Each task demonstrates practical implementation using industry-relevant Cloud and DevOps tools.

## 🚀 Project Details

### Task 01 – Docker Deployment Using Ansible

Automated Docker installation and Nginx container deployment using Ansible playbooks on Ubuntu.

**Key Features:**
- Automated Docker installation.
- Docker service management.
- Nginx image deployment.
- Ansible playbook execution.

📂 [View Task 01 Documentation](Task-01-Ansible-Docker/README.md)

### Task 02 – AWS Infrastructure Using Terraform

Provisioned AWS infrastructure using Terraform and Infrastructure as Code (IaC).

**Key Features:**
- AWS provider configuration.
- EC2 instance provisioning.
- Security Group configuration.
- Terraform initialization and deployment.

📂 [View Task 02 Documentation](Task-02-Terraform-AWS/README.md)

### Task 03 – Multi-Environment Deployment Using Docker Compose

Created separate development and production Nginx environments using Docker Compose.

**Key Features:**
- Multiple container management.
- Development environment on port 8081.
- Production environment on port 8082.
- Custom Nginx configuration.

📂 [View Task 03 Documentation](Task-03-Docker-Compose/README.md)

### Task 04 – GitHub Webhook Integration with Jenkins

Integrated GitHub Webhooks with Jenkins to automatically trigger builds when code changes are pushed.

**Key Features:**
- GitHub repository integration.
- Jenkins job configuration.
- Webhook configuration.
- Automatic build triggering.

📂 [View Task 04 Documentation](Task-04-GitHub-Jenkins-Webhook/README.md)

### Task 05 – Docker Deployment on AWS EC2

Deployed an Apache web server inside a Docker container on an AWS EC2 Ubuntu instance.

**Key Features:**
- Docker installation on EC2.
- Apache image deployment.
- Container management.
- Public IP-based website access.

📂 [View Task 05 Documentation](Task-05-Docker-Deployment-EC2/README.md)

### Task 06 – Jenkins CI/CD Pipeline with Docker Hub

Implemented a Jenkins pipeline to automate Docker image building and publishing to Docker Hub.

**Key Features:**
- Jenkinsfile configuration.
- GitHub integration.
- Automated Docker image building.
- Docker Hub authentication.
- Automated image publishing.

📂 [View Task 06 Documentation](Task-06-Jenkins-DockerHub-CICD/README.md)
