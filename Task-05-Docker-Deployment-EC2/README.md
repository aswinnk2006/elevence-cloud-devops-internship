# Task 05 – Docker Deployment on AWS EC2

## Project Overview
This project demonstrates deploying an Apache web server using Docker on an AWS EC2 Ubuntu instance.

## Objective
To deploy a containerized web server on AWS EC2 and access it through a public IP address.

## Technologies Used
- Amazon Web Services (AWS)
- EC2
- Docker
- Apache HTTP Server
- Ubuntu Linux

## Implementation
1. Created an AWS EC2 instance.
2. Connected to the instance using SSH.
3. Installed Docker.
4. Verified Docker installation.
5. Pulled the Apache HTTP Server image from Docker Hub.
6. Created and started an Apache container.
7. Configured the required port mapping.
8. Configured AWS Security Group inbound rules.
9. Accessed the Apache website using the EC2 public IP address.

## Expected Result
Successfully deployed an Apache web server inside a Docker container on AWS EC2 and accessed it through a web browser.

## Key Learning Outcomes
- AWS EC2 management.
- Docker image management.
- Container deployment.
- Linux commands.
- AWS Security Groups.
- Cloud-based web hosting.
