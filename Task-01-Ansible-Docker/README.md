# Task 01 – Docker Deployment Using Ansible

## Project Overview

This project demonstrates automated Docker installation and Nginx container deployment using Ansible on an Ubuntu server.

## Objective

To automate Docker installation, service management, and container deployment using an Ansible playbook.

## Technologies Used

- Ansible
- Docker
- Ubuntu Linux
- Nginx
- YAML

## Implementation

1. Installed and configured Ansible.
2. Created an Ansible project directory.
3. Configured Ansible inventory.
4. Created a Docker deployment playbook.
5. Installed Docker using Ansible.
6. Started and enabled the Docker service.
7. Pulled the Nginx Alpine image.
8. Deployed an Nginx container.
9. Accessed the Nginx website through the browser.

## Expected Result

Successfully automated Docker installation and deployed an Nginx web server using Ansible.

The Nginx welcome page was displayed successfully in the browser.

## Key Learning Outcomes

- Ansible playbooks and YAML syntax.
- Infrastructure automation.
- Docker image management.
- Container deployment.
- Linux server administration.
