# Task 04 – GitHub Webhook Integration with Jenkins

## Project Overview
This project demonstrates automatic Jenkins job triggering through GitHub Webhooks.

## Objective
To automate the CI/CD trigger process whenever code changes are pushed to GitHub.

## Technologies Used
- Git
- GitHub
- Jenkins
- AWS EC2
- Webhooks
- Ubuntu Linux

## Implementation
1. Configured Jenkins on an AWS EC2 instance.
2. Created a project repository on GitHub.
3. Configured Jenkins job settings.
4. Enabled GitHub integration in Jenkins.
5. Configured the GitHub Webhook.
6. Connected the GitHub repository with Jenkins.
7. Made code changes locally.
8. Pushed changes using Git.
9. GitHub sent a webhook notification to Jenkins.
10. Jenkins automatically triggered the configured job.

## Expected Result
Successfully integrated GitHub Webhooks with Jenkins to automatically trigger builds after code changes.

## Key Learning Outcomes
- Git and GitHub integration.
- Jenkins job configuration.
- Webhook functionality.
- Automated build triggering.
- CI/CD fundamentals.
