# Task 03 – Multi-Environment Deployment Using Docker Compose

## Project Overview
This project demonstrates managing multiple Nginx containers using Docker Compose.

## Objective
To deploy and manage separate development and production environments using Docker Compose.

## Technologies Used
- Docker
- Docker Compose
- Nginx
- YAML
- Windows

## Implementation
1. Installed Docker Desktop.
2. Configured Docker Compose.
3. Created a project directory.
4. Created a custom website directory.
5. Configured Nginx settings.
6. Created a Docker Compose YAML file.
7. Configured development and production services.
8. Exposed development on port 8081.
9. Exposed production on port 8082.
10. Started services using `docker compose up -d`.
11. Verified running containers.
12. Accessed both websites through the browser.

## Project Output
- Development: http://localhost:8081
- Production: http://localhost:8082

Both Nginx environments were successfully deployed and accessed locally.

## Key Learning Outcomes
- Docker Compose.
- Multi-container management.
- Environment configuration.
- Port mapping.
- Nginx configuration.
